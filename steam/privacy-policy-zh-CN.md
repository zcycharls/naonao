# Naonao: Focus Quest 隐私政策

生效日期：2026 年 7 月 15 日

Naonao: Focus Quest 是一款具有离线核心和可选第三方连接的单人游戏。

## 数据处理

游戏不要求创建 Naonao 账号，不包含广告、分析、开发者遥测或开发者代理服务器，开发者不会出售个人信息。

游戏会在玩家当前 Windows 账户的本地应用数据目录中保存游戏进度，包括任务文字、AI 生成关卡、专注记录、设置和解锁进度。游戏会在同一目录维护 `.bak` 恢复副本；检测到损坏文件时会将其保留为 `.corrupt` 文件。上述文件都不会由游戏自动上传。

本地存档路径：`%APPDATA%\Naonao Focus Quest\focus-quest-save.json`

玩家可以在退出游戏后删除该目录中的 `focus-quest-save.json*` 文件以彻底清除游戏进度及恢复副本。卸载游戏是否删除这些文件取决于 Steam 和 Windows 的卸载行为，游戏本身不会远程保留副本。

## 可选模型服务

玩家可以自行配置 Hermes Agent 或 OpenAI 兼容模型服务。只有玩家点击生成并确认本次发送后，游戏才会向玩家填写的地址发起请求。

每次 AI 生成请求都会固定发送当前任务、等级、连续天数和累计专注分钟；“最近 5 条已完成任务名称”选项默认关闭，玩家开启后才会额外发送这些任务名称。游戏不会发送本地存档文件、飞书 Webhook 或其他任务记录。

模型服务由玩家选择，其处理行为、保存期限和费用受该服务自身条款与隐私政策约束。开发者不经手或保存这些请求。

## 可选飞书回执

玩家可以配置自己的飞书机器人 Webhook，并分别选择发送专注完成和现实任务完成回执。消息会直接发送到飞书，可能包含任务名称、专注时长、连续天数和奖励结果。该功能默认关闭。

## 密钥

模型 API Key 与飞书 Webhook 使用 Electron `safeStorage` 加密保存在当前 Windows 账户下，不写入普通 JSON 存档，也不会返回给游戏页面。玩家可以在连接设置中单独清除。

## 儿童隐私

游戏不会主动收集儿童或其他玩家的个人信息。玩家不应在本地任务文字中记录不希望保存在电脑上的敏感信息。
