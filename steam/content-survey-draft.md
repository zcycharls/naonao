# Steam 内容调查草稿

以下内容是根据当前代码得出的填写依据，不代替发行方对素材来源和最终构建的确认。

## 生成式 AI

- 游戏运行时生成 AI 内容：是，可选。
- 游戏运行时调用 AI 服务或模型：是，由玩家配置 Hermes Agent 或 OpenAI 兼容端点。
- 预生成 AI 内容：待确认。

实时生成内容包括：任务关卡名称、一句任务简报、3–5 个任务步骤、宠物陪伴提示和游戏内收藏品名称。内容只显示给发起请求的玩家，不会发布给其他玩家。

### 实时生成防护

- 模型只能返回固定 JSON 结构，不提供开放聊天界面。
- 系统提示把玩家任务视为数据，禁止执行其中的指令。
- 不暴露工具、文件、Shell、系统命令或自主代理权限。
- 字段长度、关卡数量、控制字符和 HTML 在本地校验。
- 暴力伤害、爆炸物、儿童性内容等高风险输出会被本地拒绝，不写入存档。
- 服务超时、非 JSON、超大响应或校验失败时不使用生成内容；玩家仍可使用离线导演。

必须核实 `naonao-pet.png`、`hat.png`、应用图标、金属纹理、商店图和宣传文案的制作来源。只要任何随游戏或商店页发布的内容由生成式 AI 预先生成，就应按 Steamworks 当前问卷如实披露。

## 在线功能与数据

- 联机或多人：无。
- Naonao 账号：无；可选模型服务可能要求玩家拥有该服务自己的账号或 API Key。
- 聊天或用户生成内容：无。
- 广告、内购或外部支付：无。
- 遥测或分析：无。
- 开发者服务器收集或上传个人数据：无，游戏没有开发者后端或遥测。
- 玩家主动发送给模型服务：每次 AI 生成请求都会固定发送当前任务、等级、连续天数和累计专注分钟；“最近 5 条已完成任务名称”选项默认关闭，玩家开启后才会额外发送这些任务名称。
- 玩家主动发送给飞书：勾选的完成回执，可能包含任务名称和专注数据。

模型与飞书请求直接从玩家电脑发送到玩家配置的第三方地址。API Key 与 Webhook 使用 Windows 本地加密存储。

## 内容分级初步判断

当前版本未设计暴力、血腥、色情、赌博、毒品、粗俗语言或恐怖内容。最终答案仍应以提交审核的实际画面、文本、音频和商店素材为准。
