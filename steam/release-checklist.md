# Steam 发布检查表

## 账号与时间

- [ ] Steamworks 合作伙伴、税务和银行资料已通过。
- [ ] App fee 已支付，AppID 与 Depot ID 已分配。
- [ ] 已满足首发等待期和 Coming Soon 页面最短展示期。
- [ ] 商店页与构建至少在目标发布日期前预留官方建议的审核时间。

## 权利与披露

- [ ] 游戏名称、宠物图、帽子、图标、纹理、字体、音频和商店素材均有商业使用权证据。
- [ ] 预生成 AI 内容来源已核实并按实际情况披露。
- [ ] 实时生成 AI 的内容类型、第三方数据传输和本地防护已在 Steam 内容调查中如实披露。
- [ ] 商店描述只声明当前构建已实现的功能。
- [ ] 隐私政策中的发行方和公开联系渠道已填写，并托管到公开网址。
- [ ] 第三方许可证随 depot 保留。

## 商店页

- [ ] 已按 Steamworks 后台当前尺寸和内容规则制作全部 capsule、library、logo 与截图素材。
- [ ] 至少一张截图清楚展示真实主界面和计时玩法。
- [ ] 系统需求已在对应最低配置真机验证。
- [ ] 语言、平台、输入方式、单人、离线核心和可选联网声明准确。
- [ ] 未勾选未实现的 Steam 云、Steam 成就、控制器、联机或创意工坊。

## 构建

- [ ] `npm ci` 和 `npm run release:check` 全部通过；不得只以源码 smoke 或旧 depot 作为发布依据。
- [ ] `dist/steam/win-unpacked` 中只有 Steam 版，不含原客户端、本地模型、飞书 SDK、Lark SDK、ONNX 或 Transformers 运行时。
- [ ] Hermes、OpenAI 兼容端点和飞书 Webhook 均在默认关闭状态，密钥使用 `safeStorage` 加密。
- [ ] 模型生成必须逐次确认，最近任务名称共享默认关闭，离线导演在断网时可用。
- [ ] Steam 启动项指向 `NaonaoFocusQuest.exe`。
- [ ] 从 Steam 测试分支完成全新安装、启动、退出和更新测试。
- [ ] 运行中的旅程在退出并重新打开后能正确恢复或结算。
- [ ] 桌面伴侣默认关闭，开启和关闭行为正确。
- [ ] Windows 100%、125%、150% 缩放下无文字截断或控件重叠。
- [ ] 卸载和重装后的本地存档行为与隐私政策一致。

## 审核

- [ ] 商店页审核已通过。
- [ ] 构建审核已通过。
- [ ] 发布选项和发布日期由发行方最终确认。
- [ ] `npm run verify:submission` 已使用最终 VDF、隐私政策和发行资料通过。
