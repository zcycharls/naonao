# 孬孬新手教程

> 面向第一次使用孬孬的人。本文按 MECE 原则组织：每一章只解决一种新手任务，章节之间不重复覆盖。
>
> 孬孬只维护 Electron 桌面客户端；`naonao.help` 只是介绍和安装包下载页，不是网页端。

## 0. 先知道孬孬能帮你做什么

孬孬是一只桌面陪伴宠物，核心目标不是“替你完成所有事情”，而是帮你把注意力拉回当下：

- 你不知道先做什么时，用“任务锚点”写下当前任务。
- 你想开始一段专注时，用“番茄钟”和“一起专注”进入工作状态。
- 你突然冒出别的想法时，用“想法冰箱”先冻起来，避免打断当前任务。
- 你需要外部提醒时，用“飞书监督”或“长远任务监督”定时追问进度。
- 你想让孬孬更懂你时，用 AI、Hermes Agent 或本地记忆。

## 1. 安装与打开

### 1.1 下载

1. 打开 `https://naonao.help`。
2. 下载 Windows 安装包。
3. 运行安装包，按提示安装。

安装完成后，安装器会创建名为“孬孬”的桌面快捷方式和开始菜单快捷方式。

### 1.2 第一次打开

1. 双击“孬孬”快捷方式。
2. 桌面上会出现孬孬宠物。
3. 如果出现首次引导，按 3 步走：
   - 第 1 步：点“好呀！”进入设置。
   - 第 2 步：可填写 API Key，也可以点“跳过”。
   - 第 3 步：写下当前任务，例如“写周报第一段”，再点“开始专注”。

如果你暂时没有 API Key，也可以先使用任务、番茄钟、想法冰箱和统计；AI 对话能力会受限。

## 2. 基础入口

### 2.1 宠物托盘

把鼠标移到孬孬附近，会看到几个按钮：

- `◌`：展开聊天窗口。
- `⚙`：打开设置。
- `◎`：打开长远任务。
- `−`：最小化。
- `✕`：退出。
- `↘`：拖动调整宠物大小，点击可切换大小。

### 2.2 聊天窗口

点 `◌` 后会打开聊天窗口。你可以：

- 在底部输入框里直接和孬孬说话。
- 点上传按钮发送图片。
- 点清空按钮清空当前对话显示。
- 点最小化按钮收起聊天窗口。

如果已配置 API Key、Hermes Agent 或本地模型，孬孬会使用对应能力回复；如果没有配置，仍会保留基础陪伴和任务工具。

## 3. 日常专注流程

这一章是最推荐的新手使用顺序：先定任务，再开番茄，过程中收纳杂念，结束后看统计。

### 3.1 设一个任务锚点

1. 打开聊天窗口。
2. 在“加个任务…（回车确认）”输入框里写当前任务。
3. 按 Enter。

任务会成为当前 active 任务。孬孬之后的提醒、番茄完成提示、飞书监督都会优先围绕这个任务。

你可以在任务上做这些操作：

- 点击任务行：切换当前任务。
- 点击任务标题：重命名。
- 点 `+ 子步骤`：手动增加下一步。
- 点 `✦ AI 帮我拆`：让 AI 把任务拆成子步骤；需要已配置可用 AI。
- 点子步骤前的圆点：标记完成。
- 点 `⋯`：重命名、标记完成或删除任务。

### 3.2 开始一个番茄

1. 点聊天窗口顶部的 `● 专注`。
2. 点“开始”。
3. 如果当前没有任务，孬孬会先问“这一段想推进什么？”。
4. 写一句目标后点“记下来，开始”，或点“先不写，开始”。

默认流程是 25 分钟专注、5 分钟休息。专注完成后：

- 番茄数会增加。
- 数据统计会记录本次专注。
- 如果当前任务有未完成子步骤，孬孬会提示下一步。
- 休息时会询问刚才感觉怎么样，记录心情趋势。

### 3.3 开启一起专注

在聊天窗口顶部点 `◉`。开启后孬孬会进入“一起专注”状态；如果同时运行番茄钟，宠物会更安静，减少干扰。

适合场景：

- 你需要一个“有人陪着我做事”的感觉。
- 你不想频繁和 AI 对话，只想保持工作状态。
- 你容易因为桌面动效分心。

### 3.4 使用想法冰箱

当你正在做 A，脑子里突然冒出 B：

1. 点聊天窗口右下的 `◇`。
2. 在输入框写下突然出现的想法。
3. 按 Enter 或点冷冻按钮。

之后你可以：

- 点 `▧`：把这条想法取用为任务锚。
- 点 `✕`：删除这条想法。

原则：只把会打断当前任务的想法放进冰箱，不把它当成完整待办系统。

### 3.5 查看数据统计

点聊天窗口顶部的 `▥`，打开数据统计面板。这里会显示：

- 番茄统计：今日、本周、连续打卡、累计专注分钟。
- 打卡日历：最近 4 周有没有完成番茄。
- 想法冰箱：当前冷冻了多少想法。
- 专注趋势：近 7 天或 30 天番茄趋势，并显示心情记录。

统计只服务于复盘，不建议把它当成压力来源。新手只看一个指标就够：今天有没有开始过一次。

## 4. AI 与模型设置

打开设置：点宠物托盘或主界面的 `⚙`。设置左侧有“模型、对话、外观、工作区、安全、记忆与上下文、提供方、工具与密钥、高级、关于”。

### 4.1 使用云端 API

进入“模型”：

1. 选择 `Anthropic` 或 `OpenAI 兼容`。
2. 填写 `API KEY`。
3. 可选填写“模型名称”。
4. 如果选择 `OpenAI 兼容`，可填写 `Base URL`。
5. 点“保存并连接”。

注意：自定义 Base URL 会接收你的消息和 API Key。非官方或非本机地址会触发确认，只填写你信任的服务。

### 4.2 使用本地 AI 模型

进入“模型”里的“本地 AI 模型（免费离线）”：

1. 点“下载并加载模型”。
2. 等待约 460MB 模型下载完成。
3. 完成后可离线使用本地模型。

如果模型已下载但未加载，按钮会显示“加载本地模型”。如果不再需要，可点“删除本地模型”。

### 4.3 选择哪种方式

- 想省事、回复质量优先：配置云端 API。
- 想免费离线、能接受能力较弱：下载本地模型。
- 已经运行 Hermes Agent：在“记忆与上下文”连接 Hermes Agent。
- 只想用任务和番茄：可以暂时不配置 AI。

## 5. 个性化设置

### 5.1 调整提醒频率

进入“对话”：

- `关闭`：不主动打招呼。
- `低`：约 20 分钟。
- `中`：约 10 分钟。
- `高`：约 5 分钟。

如果你容易被打断，建议从“低”或“关闭”开始。

### 5.2 调整宠物动效

进入“外观”：

- `活泼模式`：保留空闲动画和点击反馈。
- `安静模式`：关闭空闲动画，只保留点击反馈。

如果你在写作、编程、阅读，建议用安静模式。

### 5.3 重做首次引导

进入“高级”，点“重新引导（重新显示首次欢迎）”。应用会清除引导标记并重新加载。

## 6. 外部监督

外部监督适合“只靠桌面提醒不够”的场景。新手不需要一开始就配置。

### 6.1 飞书自动监督

进入“提供方”里的“飞书监督”：

1. 勾选“开启飞书自动监督”。
2. 填写飞书机器人 Webhook。
3. 设置“每隔多少分钟提醒一次”，范围是 1-240 分钟。
4. 点“发送测试提醒”。
5. 点“保存并连接”。

启用后，孬孬会按间隔发送当前任务和下一步提醒。

### 6.2 飞书应用机器人

如果你希望孬孬读取你的飞书回复，进入“提供方”里的“飞书应用机器人（可读取回复）”：

1. 在飞书开放平台创建自建应用。
2. 启用机器人能力。
3. 订阅 `im.message.receive_v1`。
4. 在孬孬里填写 `App ID` 和 `App Secret`。
5. 点“连接飞书应用”。
6. 在飞书里给机器人发一句话，孬孬会自动记录最近会话。

配置成功后，定时监督会优先发到最近会话。

### 6.3 长远任务监督

点宠物托盘的 `◎`，或进入“工作区”点“长远任务监督”的“打开”：

1. 点“添加”。
2. 填写任务名称，例如“毕业论文”。
3. 填写目标说明，例如“本周完成第一章初稿”。
4. 设置提醒间隔。
5. 填写这个任务专用的飞书机器人 Webhook。
6. 勾选启用。
7. 可先点“测试”，确认能收到提醒。
8. 点保存。

长远任务和当前任务锚点是两套东西：长远任务追踪长期目标，任务锚点只负责此刻正在做什么。

## 7. 记忆与隐私

### 7.1 Hermes Agent

进入“记忆与上下文”里的“Hermes Agent（官方 sidecar）”：

1. 先在本机运行官方 Hermes Agent，并开启 API Server。
2. 勾选“连接官方 Hermes Agent API Server”。
3. 填写 API Base URL，默认是 `http://127.0.0.1:8642/v1`。
4. 如有 Key，填写 API Key。
5. 点“测试 Hermes 连接”。
6. 点“保存并连接”。

启用后，孬孬聊天和飞书汇报回复会优先交给 Hermes Agent。

### 7.2 本地长期记忆 fallback

同一页里可以勾选“启用本地长期记忆和自我学习”。孬孬会从聊天和飞书汇报里沉淀偏好、工作模式和复盘结论。

你可以：

- 点“查看记忆摘要”查看当前记忆。
- 点“清空记忆”删除本地 Hermes 记忆。

本地记忆不会删除任务、统计、心情、想法冰箱或飞书配置。

### 7.3 数据保存在哪里

孬孬是桌面客户端。任务、统计、心情、想法冰箱、Hermes 记忆和密钥类信息会保存在本机；敏感信息通过系统加密存储。

安全原则：

- API Key 不要发给不可信服务。
- 自定义 Base URL 只填你信任的地址。
- 非本机 Hermes 或 OpenAI 兼容 Base URL 会在发送 Key 前要求确认。
- `naonao.help` 不承载产品功能，只提供介绍和下载。

## 8. 常见问题

### 8.1 孬孬不会回复或回复很弱

先检查“模型”：

1. 是否已经保存 API Key。
2. 是否选择了正确的提供商。
3. OpenAI 兼容 Base URL 是否正确。
4. 如果不用 API，是否已下载并加载本地模型。

### 8.2 本地模型下载失败

1. 检查网络。
2. 重新点“下载并加载模型”。
3. 如果下载卡住，可先点“取消”，再重新下载。
4. 进入“高级”查看日志。

### 8.3 飞书收不到提醒

1. 确认 Webhook 是 `https://open.feishu.cn/open-apis/bot/v2/hook/...` 或 `https://open.larksuite.com/open-apis/bot/v2/hook/...`。
2. 先点“发送测试提醒”。
3. 确认已经点“保存并连接”。
4. 如果使用飞书应用机器人，确认 App ID、App Secret 和事件订阅已配置。

### 8.4 主动提醒太打扰

进入“对话”，把主动打招呼频率改成“低”或“关闭”。同时可以进入“外观”，切到“安静模式”。

### 8.5 想重新开始引导

进入“高级”，点“重新引导（重新显示首次欢迎）”。

## 9. 新手 7 天用法

### 第 1 天：只用任务锚点

只做一件事：每天打开孬孬，写下“我现在要做什么”。

### 第 2 天：加一个番茄

写任务后，点 `● 专注`，完成一个 25 分钟专注。

### 第 3 天：用想法冰箱

专注中一旦想到别的事，先放进 `◇`，不要立刻切任务。

### 第 4 天：看一次统计

点 `▥` 看今日番茄和连续打卡，不做复杂复盘。

### 第 5 天：调低干扰

把主动打招呼频率调成“低”，把宠物模式切成“安静模式”。

### 第 6 天：配置 AI

选择云端 API、本地模型或 Hermes Agent 中的一种，不要三种一起折腾。

### 第 7 天：再加外部监督

如果你发现桌面提醒不够，再配置飞书监督或长远任务监督。

## 10. 一句话工作流

每天打开孬孬后按这个顺序走：

1. 写下当前任务。
2. 拆出下一步。
3. 开一个番茄。
4. 杂念放进冰箱。
5. 完成后看统计，不责备自己。
